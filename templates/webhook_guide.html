TradingView Webhook Bridge Guide

Trigger automated Dhan trades directly from your custom TradingView Pine Script alerts

Your Local Webhook Endpoint URL http://localhost:5000/webhook

To connect TradingView cloud alerts to your local machine, run ngrok http 5000 or deploy on a VPS.

1. Buy Call Option (Bullish Entry)

Paste this JSON into your TradingView Alert Message box:

{
  "secret": "dhan_algo_secure_token",
  "action": "BUY_CE",
  "symbol": "NIFTY",
  "strike_offset": 0,
  "comment": "Bullish 5m Supertrend Breakout"
}

2. Buy Put Option (Bearish Entry)

Paste this JSON into your TradingView Alert Message box:

{
  "secret": "dhan_algo_secure_token",
  "action": "BUY_PE",
  "symbol": "NIFTY",
  "strike_offset": 0,
  "comment": "Bearish EMA Crossover Breakdown"
}

3. Exit / Square-Off Position 

{
  "secret": "dhan_algo_secure_token",
  "action": "SQUARE_OFF",
  "comment": "Target 2 Reached or Stop Loss Hit"
}
